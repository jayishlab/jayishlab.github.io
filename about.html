About Jayish Lab

Jayish Lab is the personal website of Aman Kumar, a life-sciences undergraduate trained in bioinformatics through Wellcome Connecting Science and University of Leeds programmes.

Why I built Jayish Lab

Two reasons. First, to make my own bioinformatics work faster. Second — and more importantly — to help students who do not know any code at all. If you can open a web page, you can use these tools. No terminal, no installs, no programming needed.

How the code is written

Code developed with AI assistance and by me. I write code with AI help, then I correct it, test it and verify the results myself. Only after that do I publish it. Every formula used in these tools is cross-checked against published literature before release, and known limitations are stated openly on each tool page.

Privacy promise

All Jayish Lab tools are simple UI-based tools that run entirely inside your browser. There is no login and no account, and no personal data or file is ever shared with any server — your sequences cannot leave your computer, because they are never uploaded. Even as Jayish Lab grows in the future, this rule will not change: no login, browser-based only.

Suggestions welcome

Jayish Lab is built for students, so students decide what comes next. If you want a new tool, or want to suggest an improvement to an existing one, you are welcome to suggest it on the GitHub repository.
